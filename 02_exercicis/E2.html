11.2 Constants i immediats

Vegeu Secció 2.6.2 i RISC-V 2.14.

Exercici 11.3 Donades les declaracions de variables següents, emmagatzemades a partir de l’adreça 0x10010000:

RV32I
.data
A: .word 5, 2
B: .word 3
C: .word 4, 0x0FFFF, 0x4180
D: .word 0x10010008, 0

Tots els apartats parteixen del mateix estat inicial.

  1. Quin és el valor final de la variable B després d’executar el codi següent?
RV32I
.text
la   t1, C
lw   t2, 12(t1)
lb   t1, 8(t2)
la   t3, B
lb   t4, 0(t3)
add  t1, t1, t4
sb   t1, 0(t3)
  1. Explica textualment i de forma concisa què fa el fragment següent:
RV32I
.text
la  t1, A+1
lw  t1, 0(t1)

Nota: La sintaxi la label+offset és admesa a EC (teoria i exàmens), però a RARS cal substituir-la per la + addi. A més, lw sobre una adreça no múltiple de 4 genera una excepció d’alineació.

Exercici 11.4 Indica quin és el contingut de memòria a partir de l’adreça 0x10010000, a nivell de paraula, per a la declaració de variables globals següent:

RV32I
.data
        .byte  0, 1, 2
A:      .byte  5, -1
B:      .half  0x66
C:      .word  4, 0x0FDF
D:      .half  3
E:      .byte  25
F:      .byte  0x08
G:      .dword 0x10010008

Exercici 11.5 En RISC-V, la pseudoinstrucció li rd, imm s’expandeix en instruccions reals quan l’immediat no cap en 12 bits amb extensió de signe.

  1. Quina seqüència d’instruccions genera l’assemblador per carregar el valor 0xDEADBEEF al registre t0? Calcula els valors exactes dels operands de cada instrucció.
  2. Per què cal ajustar el camp immediat d’addi quan el bit 11 del valor original és 1? Il·lustra-ho amb el valor 0xDEADBEEF.
  3. Quin és el rang de valors immediats que accepta addi (és a dir, el rang de constants que es pot carregar a un registre amb addi rd, zero, imm)? I quin és el rang de constants que es pot carregar a un registre amb la seqüència lui + addi?

Exercici 11.10 RISC-V és una arquitectura little-endian.

  1. Explica què significa little-endian i en quin ordre s’emmagatzemen els bytes d’un enter de 32 bits a memòria.
  2. La variable global int x = 0x12345678 s’emmagatzema a partir de l’adreça 0x10010000. Indica el contingut byte a byte de les adreces 0x10010000 a 0x10010003.

Escriu un programa en assemblador que sumi els naturals representats per u1 i u2 i deixi el resultat en binari (natural) a d3. Com que cada operand és un sol dígit (rang \([0, 9]\)), la suma màxima és \(9+9=18\) i sempre cap en un sol byte.

Exercici 11.14 Escriu en hexadecimal el contingut de memòria ocupat per les declaracions següents, suposant que comencen a emmagatzemar-se a partir de l’adreça 0x10010000. 11.7 Punters

Vegeu Secció 2.7.

Exercici 11.19 Suposem les declaracions en C:

C
int *m1, *m2;   /* m1 i m2 són punters a int (en memòria) */
int main() {
    int *r1, *r2;   /* r1 i r2 són punters a int (en registre) */
    ...
}

Suposant que r1 i r2 ocupen els registres t1 i t2, tradueix a assemblador RISC-V les sentències en C següents, pertanyents a main:

  1. r1 = r2;
  2. *r1 = *r2;
  3. m1 = m2;
  4. *m1 = *m2;

Exercici 11.20 Donada la declaració de dades global en C:

C
int *pdada;

Tradueix a una única sentència en C el conjunt d’instruccions de cada apartat:

RV32I
la   t0, pdada
lw   t0, 0(t0)
lw   t1, 0(t0)
addi t1, t1, 4
sw   t1, 0(t0)
RV32I
la   t0, pdada
lw   t1, 0(t0)
addi t1, t1, 4
sw   t1, 0(t0)
RV32I
la   t0, pdada
lw   t0, 0(t0)
lw   t1, 0(t0)
addi t0, t0, 4
sw   t1, 0(t0)

Exercici 11.21 Donades les declaracions en C:

C
int vec[6] = {2, 4, 0, 6, 8, 0};
int *punter;

Tradueix a una única sentència en C el conjunt d’instruccions de cada apartat:

RV32I
la   t0, punter
la   t1, vec+8
sw   t1, 0(t0)
RV32I
la   t0, punter
lw   t1, 0(t0)
addi t1, t1, 4
sw   t1, 0(t0)
RV32I
la   t1, vec
lw   t3, 0(t1)
lw   t4, 4(t1)
add  t3, t3, t4
sw   t3, 4(t1)
RV32I
la   t1, vec
la   t0, punter
lw   t2, 0(t0)
lw   t3, 0(t2)
addi t3, t3, 1
sw   t3, 8(t1)
RV32I
la   t0, punter
lw   t2, 0(t0)
lw   t3, 0(t2)
addi t3, t3, 1
sw   t3, 8(t2)

Exercici 11.22 Donades les declaracions de variables globals en C:

C
char      *punterc;

int       *punteri;
long long *punterd;

Tradueix a assemblador RISC-V les sentències següents:

  1. punterc++;
  2. punteri++;
  3. punterh++;
  4. punterd++;
  5. *punteri = *punteri + 5;
  6. *punterh = *punterh + 10;

Exercici 11.23 Donades les declaracions en C:

C
char          a;

Tradueix a assemblador RISC-V les sentències en C següents, pertanyents a main:

  1. q = q + 1;

  3. h = &c;
  4. b = *(q + b);
  5. *h = *(h + b);
  6. p[*q + 10] = a;

Exercici 11.24 Donades les declaracions en C:

C

Tradueix a assemblador RISC-V les sentències en C següents:

  1. pdada = &dada;

  3. pdada = pdada + 1;
  4. dada = dada - 1;

11.8 Vectors

Vegeu Secció 2.8 i Secció 2.8.5.

Exercici 11.25 Donades les declaracions en C:

C
char  indx[100];    /* enters d'1 byte */
short meitat[100];  /* enters de 2 bytes */
int   val[100], vec[100];  /* enters de 4 bytes */
int main() {
    char c;
    int  i, j;
    ...
}

Tradueix les sentències en C següents, suposant que i, j i c ocupen els registres t0, t1 i t2:

  1. i = val[5] + vec[10];
  2. i = vec[10 + val[5]];
  3. c = indx[i + val[j]];
  4. c = indx[meitat[i]];
  5. i = meitat[vec[i] + val[j]];
  6. i = val[meitat[i]] + vec[j];
  7. i = vec[indx[i]] - val[j];
  8. i = meitat[indx[val[j]]];

Exercici 11.26 Donades les declaracions en C:

C
int v[10];
int main() {
    int i, suma = 0;  /* i a t0, suma a t1 */
    ...
}
  1. Escriu en assemblador RISC-V el bucle que inicialitza tots els elements de v a zero.
  2. Escriu el bucle que calcula la suma de tots els elements de v i deixa el resultat a suma.
  3. Escriu el bucle que copia els elements de v al revés en un nou vector w de la mateixa mida declarat a continuació de v.

Exercici 11.27 Donada la declaració en C:

C
int vec[100];
int main() {
    int i, val;  /* i a t0, val a t1 */
    ...
}

Escriu en assemblador RISC-V un fragment de codi que cerqui el valor de val dins vec i deixi a t2 l’índex de la primera ocurrència, o −1 si no s’hi troba.

Exercici 11.28 Donades les declaracions en C:

C
short v[8] = {10, 20, 30, 40, 50, 60, 70, 80};
int main() {
    short *p = v;   /* p a t0 */
    int i;          /* i a t1 */
    ...
}
  1. Escriu en assemblador RISC-V la sentència p = v + 3; i explica de quants bytes s’incrementa el punter.
  2. Escriu el bucle que, usant el punter p, dobla el valor de cada element del vector.

C

char         minus[N+1];
unsigned int vec[N] = {70, 85, 78, 67, 73, 79, 78, 65};

int main() {
    int i = 0;

        i++;
    }
    minus[N] = 0;
}
