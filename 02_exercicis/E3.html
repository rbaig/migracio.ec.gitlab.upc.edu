12.1 Operacions lògiques i desplaçaments

Vegeu Secció 3.1 i Secció 3.2.

Exercici 12.1 Calcula el resultat en hexadecimal de les operacions lògiques bit a bit següents amb 16 bits:

  1. 0x7654 | 0x3333
  2. 0x7654 & 0x3333
  3. 0x7654 << 2
  4. 0x7654 >> 3 (desplaçament lògic)

Exercici 12.2 Donada la sentència en C:

C
C = A ^ B;

Tradueix-la a assemblador RISC-V sense utilitzar la instrucció xor. Recorda que l’operació és equivalent a:

C
C = (~A & B) | (A & ~B);

Exercici 12.3 Escriu les seqüències de codi necessàries per escriure a t1 el resultat de les condicions lògiques següents, sense fer servir instruccions de salt. El valor final de t1 ha de ser 0 si la condició no s’acompleix, o diferent de zero altrament.

  1. L’enter representat per t1 és negatiu.
  2. L’enter representat per t1 és múltiple de 4.
  3. El natural representat per t1 és tal que el seu quadrat no es pot escriure amb 32 bits.
  4. El natural representat per t1 és tal que la suma amb si mateix no es pot escriure amb 32 bits.
  5. Els bits 1, 3 i 5 de t1 valen zero.

Exercici 12.4 Programa una seqüència de no més de 6 instruccions que posi a 0 el bit \(i\)-èsim del registre t1, deixant la resta de bits intactes. Suposa que \(i\) està guardat a t2. Pots usar altres registres per a resultats temporals.

Exercici 12.5 Fes un programa que realitzi els desplaçaments següents sobre un número de 64 bits emmagatzemat als registres t2 (32 bits de més pes) i t1 (32 bits de menys pes):

  1. Desplaçament a l’esquerra d’1 posició.
  2. Desplaçament lògic a la dreta d’1 posició.
  3. Desplaçament aritmètic a la dreta d’1 posició.
  4. Desplaçament lògic a l’esquerra de \(n\) posicions (\(n < 32\)), on \(n\) ocupa t3.
  5. Desplaçament lògic a la dreta de \(n\) posicions (\(n < 32\)), on \(n\) ocupa t3.

Exercici 12.6 Suposem que el registre t0 conté dos enters de 16 bits en complement a 2: un als 16 bits de més pes i un altre als 16 bits de menys pes. Escriu una seqüència d’instruccions que extregui aquests dos números, els representi en 32 bits estenent el signe, i els guardi a t1 i t2 respectivament, sense usar cap instrucció d’accés a memòria.

Exercici 12.7 Fes un programa que compti el nombre de bits actius que hi ha al registre t1, executant el mínim d’instruccions possible i sense fer cap load. El resultat s’ha de deixar al registre t3.

Exercici 12.8 Escriu un fragment de codi assemblador RISC-V que intercanviï tots els bits parells amb els bits senars del registre t0.

Exercici 12.9 Representa el valor inicial de cada bit de t4 amb una lletra: el bit 31 és b31, el bit 30 és b30, …, el bit 0 és b0. Cada lletra denota un valor binari desconegut (0 o 1).

  1. Escriu les instruccions necessàries perquè el bit de més pes passi a ser el de menys pes i la resta de bits es desplacin una posició cap a l’esquerra.
  2. Seguint la mateixa notació, escriu el contingut del registre t4 després d’executar les instruccions següents:

Exercici 12.10 Tradueix a assemblador RISC-V el programa en C següent, suposant que a, b i c ja han estat inicialitzades als registres t1, t2 i t3:

C
int main() {
    int a, b, c, i;  /* i s'emmagatzema a t0 */

        i = b;

Exercici 12.11 Tradueix a assemblador RISC-V la sentència if del programa en C següent, que converteix un dígit hexadecimal (representat per un caràcter ASCII guardat a la variable global c) al seu valor binari equivalent i l’escriu a la variable global num (enter de 8 bits).     else
        num = c - '0';

Exercici 12.12 Tradueix a assemblador RISC-V la sentència switch del programa en C següent. La variable op ocupa el registre t0 i les variables a, b, res ocupen t1, t2, t3:

    case 0:  res = a + b;  break;
    case 1:  res = a - b;  break;

C

  4. En un processador a 2 GHz, sabent que el programa triga \(5 \times 10^{-9}\) s, quin és el CPI del programa?
