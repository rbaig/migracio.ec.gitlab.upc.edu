Tema 4: Aritmètica entera i matrius

13.1 Suma i resta

Vegeu Secció 4.2 i Secció 1.6.

Exercici 13.1 Convertiu a decimal els números 0x0D34 i 0xBA1D:

  1. Suposant que representen naturals.
  2. Suposant que representen enters en complement a 2.
  3. Suposant que representen enters en signe-magnitud.

Exercici 13.2 Siguin els números: \(A =\) 0x0D34, \(B =\) 0xDD17, \(C =\) 0xBA1D, \(D =\) 0x3617.

  1. Quant val, en hexadecimal, la suma \(A+B\) si representen naturals de 16 bits?
  2. Ídem per a la suma \(C+D\).
  3. Quant val, en hexadecimal, la suma \(A+B\) si són enters en signe-magnitud de 16 bits?
  4. Ídem per a la suma \(C+D\).

Exercici 13.3 Siguin els números: \(A =\) 0xBA7C, \(B =\) 0x241A, \(C =\) 0xAADF, \(D =\) 0x47BE.

  1. Quant val, en hexadecimal, la resta \(A-B\) si representen naturals de 16 bits?
  2. Ídem per a la resta \(C-D\).
  3. Quant val, en hexadecimal, la resta \(A-B\) si són enters en signe-magnitud de 16 bits?
  4. Ídem per a la resta \(C-D\).

Exercici 13.4 Per a les operacions següents amb naturals de 8 bits, codifiqueu els operands en binari, realitzeu l’operació i indiqueu si s’ha produït arrossegament (carry) o, en el cas de la resta, préstec (borrow). Convertiu el resultat a decimal:

  1. \(200 + 50\)
  2. \(25 + 34\)
  3. \(254 + 3\)
  4. \(128 - 20\)

Exercici 13.5 Per a les operacions següents amb enters en Ca2 de 8 bits, codifiqueu els operands en binari, realitzeu l’operació i indiqueu si s’ha produït sobreeiximent (overflow). Convertiu el resultat a decimal:

  1. \((-25) + (-34)\)
  2. \((-25) - (-34)\)
  3. \((+127) - (-20)\)
  4. \((-128) - (-20)\)

Vegeu Secció 4.2.1.

Exercici 13.6 Donades dues variables naturals de 32 bits emmagatzemades a t1 i t2, escriviu un programa que calculi la seva suma (t0 = t1 + t2) i determini si s’ha produït arrossegament (carry), desant 1 a t3 en cas afirmatiu i 0 altrament. El programa no ha de contenir cap instrucció de salt.

Indicació: si es produeix carry, el resultat t0 és menor que qualsevol dels dos sumands.

Exercici 13.7 Donades dues variables enteres de 32 bits emmagatzemades a t1 i t2, escriviu un programa que calculi la seva suma (t0 = t1 + t2) i determini si s’ha produït sobreeiximent (overflow). El programa no ha de contenir cap instrucció de salt.

Indicació: hi ha sobreeiximent si i només si els dos sumands tenen el mateix signe i el resultat té signe oposat. A RISC-V, la detecció es fa combinant instruccions de comparació i lògica de bits sobre els bits de signe.

Vegeu Secció 4.2.3 i Exemple 4.1.

Exercici 13.8 Donada la declaració en C:

long long x, y;

Traduïu a assemblador RISC-V les sentències següents (cada variable ocupa dos registres consecutius: part alta i part baixa):

  1. x = x + y;
  2. x = x - y;
  3. if (x > y) x = 1;

Exercici 13.12 Siguin x, y i z variables de 32 bits emmagatzemades a t1, t2 i t3. Escriviu un programa en RISC-V que calculi z = x * y i escrigui a t0 el valor 0 si el resultat és correcte o 1 si s’ha produït sobreeiximent. El programa no ha de fer servir cap instrucció de salt. Considereu:

  1. unsigned int x, y, z;
  2. int x, y, z;

Vegeu Secció 4.3.4.

Exercici 13.13 Completeu el contingut que han de tenir els registres operands de les instruccions següents perquè siguin coherents després de la seva execució. Considereu cada instrucció de manera independent:

  1. mul t3, t1, t2 — el resultat als 32 bits baixos és 0xFFFFFFFA; t1 = 0x00000002; calculeu el valor de t2.
  2. div t3, t1, t2 (divisió entera signada, truncament cap a zero) — t1 = 0x00000005, t2 = 0xFFFFFFFE; calculeu el quocient a t3 i el residu.
  3. En quins casos concrets pot produir-se sobreeiximent en una divisió entera signada en Ca2?

Exercici 13.17 Sigui la declaració en C:

addi t0, t0, 1384

Exercici 13.20 Donades les declaracions en C:

int mati[5][4];

void func(int veci[4]) {
    int j;
    for (j = 0; j < 4; j++)
        veci[j] = j;
}

int main() {
    int *p = &mati[0][0];
    int *fi = &mati[5][0];
    while (p != fi) {
        func(p);
        p += 4;
    }
}
  1. Traduïu a RISC-V la subrutina func utilitzant accés seqüencial al vector veci, suposant que j ocupa t0.
  2. Traduïu a RISC-V la subrutina main utilitzant accés seqüencial a la matriu mati.

13.4 Accés seqüencial

Vegeu Secció 4.6.

Exercici 13.21 Donades les declaracions en C (on N és una constant):

void func(int A[N][N]) {
    int i, j, suma = 0;
    ...
}

Traduïu a RISC-V les sentències següents usant accés seqüencial per als accessos a A, suposant que i, j i suma ocupen t0, t1 i t2:

for (i = 0; i < N; i++)
    suma += A[3][i];
for (i = 0; i < N; i++)
    suma += A[i][4];
for (i = 0; i < N; i++)
    suma += A[i][i];
for (i = 0; i < N; i += 3)
    suma += A[i][N-1-i];

Exercici 13.22 Donades les declaracions en C:

#define N 100
char      vecchar[N];
int       matint[N][N];
long long matlong[N][N];

void func() {
    int i;
    ...
}

Traduïu a RISC-V les sentències següents usant accés seqüencial, suposant que i ocupa t0:

for (i = 1; i < N; i += 2)
    vecchar[i] = N - i;
for (i = 0; i < N; i++)
    matint[i][0] = 0;
i = 4;
while (matint[3][i] != 0) {
    matint[3][i]--;
    i += 3;
}
for (i = N-1; i >= 0; i--)
    matlong[i][4] = i;

Exercici 13.23 Siguin les declaracions en C:

int   z[5][3];
int   vector[4];

void func(int i, int j) {
    int k;
    ...
}
  1. Traduïu a RISC-V la sentència següent, pertanyent a func:
vector[i] = z[4][j];
  1. El codi assemblador RISC-V següent s’ha obtingut en traduir el bucle de la dreta implementant accés seqüencial. Completeu les quatre constants inicials perquè la traducció sigui correcta:
.set offset_vector, ?
.set offset_z,      ?
.set max_dist,      ?
.set stride,        ?

func:
        la    t2, vector + offset_vector
        la    t3, z + offset_z
        addi  t6, t3, max_dist
for:
        beq   t3, t6, fifor
        lw    t4, 0(t2)
        lw    t5, 0(t3)
        add   t4, t4, t5
        sw    t4, 0(t2)
        addi  t3, t3, stride
        j     for
fifor:
        ret
for (k = 0; k < 5; k++)
    vector[2] += z[k][2];

Exercici 13.24 Donades les declaracions en C:

#define N 10

Traduïu a assemblador RISC-V el codi següent fent servir accés seqüencial amb un sol punter:

i = 0;
do {

Exercici 13.26 La funció func recorre la matriu matriu amb un punter. Suposeu que N i M són constants, amb \(N \leq M\):

int matriu[N][M];

void func() {
    int  i, *p;
    p = matriu;
    for (i = 0; i < N; i++) {
        *p  = i;
        p   = p + M + 1;
    }
}
  1. Enumereu els elements de la matriu que s’escriuen i indiqueu quin valor s’assigna a cada un.
  2. Traduïu a RISC-V el bucle anterior usant accés seqüencial, suposant que i i p ocupen t0 i t1.

Exercici 13.27 La funció fila_dispersa escriu els elements de la fila i d’una matriu dispersa, representada pels vectors A, IA i JA, a les posicions corresponents de la matriu global mat:

int mat[N][M];

void fila_dispersa(int *A, int *IA, int *JA, int i) {
    int k;
    for (k = IA[i]; k < IA[i+1]; k++)
        mat[i][JA[k]] = A[k];
}
  1. Dels accessos a memòria que fa aquest bucle (IA[i], IA[i+1], JA[k], mat[i][JA[k]], A[k]), quins es poden traduir amb accés seqüencial i quins només amb accés aleatori?
  2. Traduïu la funció fila_dispersa usant accés seqüencial per als recorreguts que ho permetin, suposant que k es guarda a t0.

Exercici 13.28 Donada la versió inicial del bucle següent (on N és una constant i v és un vector global d’enters):

fi:

  2. Apliqueu l’optimització de condició al final del bucle (do-while). Escriviu la versió optimitzada i calculeu de nou el temps total.
  3. Quina reducció percentual del temps s’obté per a \(N = 100\)?
